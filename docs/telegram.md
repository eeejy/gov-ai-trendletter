# 텔레그램 봇 만들기와 자동 실행

## 1. 봇 만들기 (5분)

텔레그램에서 **@BotFather** 를 찾아 대화한다.

```
/newbot
→ 봇 이름          : AI 정보동향지
→ 사용자명(고유)    : myagency_ai_trend_bot     ← 반드시 _bot 으로 끝나야 한다
```

토큰을 준다. `123456789:AAH...` 형태이며 **이 값이 곧 비밀번호다.**

## 2. 방 만들고 봇 초대

직원들이 받아볼 **그룹**이나 **채널**을 만들고 봇을 초대한다.

- **채널** — 담당자만 글을 올리고 직원은 읽기만. 공지용으로 적합
- **그룹** — 서로 이야기할 수 있다

채널이면 봇을 **관리자**로 올려야 글을 보낼 수 있다.

## 3. chat_id 얻기

방에 아무 글이나 하나 올린 뒤,

```bash
curl -s "https://api.telegram.org/bot<토큰>/getUpdates" | python3 -m json.tool | grep -A3 '"chat"'
```

`"id": -1001234567890` 처럼 나온다. **그룹·채널은 음수**다.

## 4. 설정에 넣기

`config/secrets.yaml` 을 만든다. 이 파일은 저장소에 올라가지 않는다.

```yaml
telegram:
  token: "123456789:AAH..."
  chat_id: "-1001234567890"          # 직원 배포용 방
  admin_chat_id: "123456789"         # 담당자 본인 (선택)
```

`admin_chat_id` 를 따로 두면 **초안 준비 알림이 전 직원에게 가지 않는다.**
본인 계정 id 는 **@userinfobot** 에게 아무 글이나 보내면 알려 준다.

확인:

```bash
python run.py telegram --check      # 봇 @이름 → 방 이름 (타입)
python run.py telegram              # 보낼 문구 미리보기
python run.py telegram --send       # 실제 발송
```

## 자동 실행 — GitHub Actions 는 쓰지 않는다

세 가지가 걸린다.

| | |
| --- | --- |
| **Claude 인증** | 지금은 로컬 `claude` CLI 를 부른다. Actions 에서 돌리려면 Anthropic API 키를 따로 발급해 Secrets 에 넣어야 하고, 구독과 별도로 사용량 요금이 붙는다 |
| **저장소가 공개** | 수집한 기사와 생성된 초안이 Actions 로그에 그대로 남는다 |
| **설계와 충돌** | 이 도구는 처음부터 *"완전 예약 대신 사람이 버튼을 누른다 — 오발행 방지"* 를 전제로 만들었다. 검토 없이 나가면 잘못된 내용이 전 직원에게 전달된다 |

## 그래서 이렇게 한다

```
  [예약]  매주 금 08:00
     ↓
  수집 → 통합 → 선별 → Claude 초안        ← 여기까지 자동 (약 1분 40초)
     ↓
  담당자에게 텔레그램 알림 「초안 준비됨」
     ↓
  담당자가 편집기에서 확인·수정
     ↓
  [발행] 버튼 → HTML 확정본
     ↓
  [텔레그램] 버튼 → 직원 방으로 요약 + 전문 링크    ← 사람이 누른다
```

### 예약 걸기

```bash
python tools_schedule.py --day 5 --time 08:00
```

안내해 주는 한 줄을 붙여 넣으면 등록된다.

- **macOS** — `launchd` (`~/Library/LaunchAgents/`)
- **Windows** — 작업 스케줄러 (`schtasks`)
- 기록은 `data/logs/weekly.log`

요일은 `1=월 … 5=금, 0=일`. 해제는 `--remove`.

### 예약이 실행하는 것

```bash
python run.py weekly --days 7
```

- 수집 → 초안 생성 → **저장하고 멈춘다**
- 담당자에게 「초안 준비됨 + 항목 목록 + 편집기 주소」 알림
- 실패하면 실패 사유를 담당자에게 알린다
- **발행도, 직원 발송도 하지 않는다**

### PC 가 꺼져 있으면

`launchd` 와 작업 스케줄러 모두 **놓친 일정을 다음 부팅 때 실행**한다.
사무실 PC 를 매일 켠다면 문제없고, 오래 자리를 비우면 그동안은 돌지 않는다.

## 매일 보내고 싶다면

같은 주 소식을 모아 6건을 고르는 구조다.

하루치로서 말이 된다. 다만 하루에 실을 만한 AI 정책 소식이
그만큼 나오지 않는 날이 많다.
