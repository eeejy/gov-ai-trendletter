## 5. 종합 항목의 사실성 점검

06번 「AI 에이전트 자율성 확대와 통제 논란」은 18개 자료를 종합했다.
확인되지 않은 주장은 아래처럼 출처와 불확실성을 함께 밝혔다.

- `…성능 저하 없이 안전성 개선 **주장**`
- `…클로드 오퍼스 4.5급 성능 구현했다는 …공개, 수치는 **검증 필요**`
- `**개발자 커뮤니티에서** 클로드가 …지웠고 …는 **반응**, 사실관계 **검증 필요**`

시사점도 근거에서 직접 끌어냈다 —
`에이전트의 700GB 삭제 사고에 비춰, 수사·정보 자료가 있는 내부망 PC에는 파일 쓰기·삭제 권한을 막고 읽기 전용 업무부터 제한 적용 필요`
