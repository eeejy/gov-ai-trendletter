# 배포 — 누가 무엇을 설치해야 하나

## 편집기는 담당자 한 명만

편집기(`run.py editor`)는 **담당자 PC에서만 도는 로컬 도구**다.
`127.0.0.1` 에만 붙으므로 다른 사람이 접속할 수 없고, 접속할 필요도 없다.
동향지를 받아보는 직원은 아무것도 설치하지 않는다.

| | 담당자 | 받아보는 직원 |
| --- | --- | --- |
| Python | 필요 | 불필요 |
| Claude Code | 필요 (초안 작성) | 불필요 |
| 편집기 | 본인 PC에서 실행 | 접속 안 함 |
| 동향지 | 만들어 발행 | **브라우저만 있으면 됨** |

## 동향지는 완전한 스탠드얼론 파일이다

발행본은 **HTML 파일 하나(약 260KB)** 이고, 아래를 전부 안에 담고 있다.

- 글꼴 (그 회차에 쓰인 글자만 잘라서)
- CSS·JavaScript 전부 인라인

바깥으로 나가는 것은 **사용자가 눌렀을 때의 기사 링크뿐**이다.
인터넷이 없어도, 폐쇄망이어도 파일만 있으면 그대로 열린다.

```bash
# 확인 방법 — 셋 다 0 이어야 한다
grep -c '<img src="https' 발행본.html
grep -c '<script src=' 발행본.html
grep -c '<link.*stylesheet' 발행본.html
```

## 전달하는 방법 세 가지

### 1. 사내 웹 주소에 올린다 (권장)

그룹웨어 게시판·사내 포털·정적 파일 서버 어디든, **브라우저로 열리는 주소**면 된다.
`config/settings.yaml` 의 `telegram.html_base` 에 그 주소를 적으면
텔레그램 메시지에 **버튼**이 붙는다.

```yaml
telegram:
  html_base: "https://intra.example.go.kr/ai-trend/"
```

- 휴대폰에서 버튼 한 번이면 열린다. **가장 편하다**
- 같은 주소를 PC 에서 열면 성운 목차가 있는 넓은 화면으로 보인다
- 담당자가 매주 파일 하나를 올려야 한다 (자동화하려면 별도 작업)

### 2. 텔레그램에 파일을 첨부한다 (호스팅이 없을 때)

`html_base` 를 비워 두면 요약 메시지 뒤에 **HTML 파일이 첨부**된다.
호스팅이 전혀 없어도 되지만, 여는 단계가 하나 더 있다.

- 안드로이드 — 파일을 누르고 브라우저 선택
- iOS — 내려받은 뒤 「파일」 앱에서 열기
- 익숙하지 않은 직원에게는 이 한 단계가 장벽이 된다

### 3. 그룹웨어·메일에 첨부한다

지금까지 PDF 를 붙이던 자리에 HTML 을 붙이면 된다.
게시판이 첨부파일을 브라우저로 열어 주면 1번과 같아지고,
내려받게만 하면 2번과 같다.

## 정리하면

**받아보는 사람 쪽은 배포할 것이 없다.** 브라우저만 있으면 된다.

담당자 쪽에서 결정할 것은 **파일을 어디에 두느냐** 하나다.
사내에서 브라우저로 열리는 주소가 하나만 있으면 가장 매끄럽고,
없으면 텔레그램 첨부로도 돌아간다.
