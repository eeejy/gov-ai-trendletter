# 텔레그램 요약

> 예시는 해양 안전·치안 분야 기관 기준이다. 쓰는 기관의 업무와 지난 발행본 문장으로 바꾼다.

발행된 「AI 정보동향지」를 텔레그램 메시지 하나로 줄인다.
**현장 직원이 휴대폰에서 30초 안에 읽는 것**이 목표다. 전문을 옮기는 것이 아니다.
제목만 보고 지나치지 않도록, 무슨 일이 있었는지 한 줄은 붙여 준다.

## 누가 읽는가

AI를 전혀 모르는 직원이 이동 중에 읽는다. 어려운 말이 하나라도 있으면 그냥 넘긴다.

## 형식 (이 틀을 그대로 지킨다)

```
📰 {{ISSUE_LABEL}} · {{PERIOD}}

{{THEME}}

1️⃣ 제목
   무슨 일이 있었는지 한 줄
   → 우리가 할 일 한 줄

2️⃣ 제목
   무슨 일이 있었는지 한 줄
   → 우리가 할 일 한 줄
```

## 규칙

- **한 항목은 세 줄.** 제목 / 무슨 일인지 / 화살표
- 제목은 **20자 안팎**으로 줄인다. 원 제목이 길면 핵심만 남긴다
- 가운데 줄은 **"무슨 일이 있었는지"**를 35자 안팎 한 문장으로.
  누가 무엇을 했는지가 드러나야 한다. 제목을 늘여 쓴 것이면 지운다
- 화살표 줄은 **"그래서 뭘 하면 되는지"**를 25자 안팎으로. 어려운 말 금지
- 전문용어를 쓰지 않는다. 각주를 달 수 없으므로 아예 쉬운 말로 바꾼다
  (`소버린 AI` → `국산 AI`, `파운데이션 모델` → `대형 AI 모델`)
- 영향이 `높음`인 항목 앞에는 `🔴` 를 붙인다
- 이모지는 번호와 영향 표시에만 쓴다
- **전체 1,000자를 넘기지 않는다.** 넘으면 가운데 줄부터 짧게 줄인다
- 링크는 넣지 않는다 (발송할 때 따로 붙는다)

## 입력

```json
{{ISSUE_JSON}}
```

## 출력

**JSON만** 출력한다. 코드펜스도 설명도 붙이지 않는다.

{"text":"📰 제2026-12호 · 8.23~8.30\n\n공공 AI 전환이 문서·민원까지\n\n1️⃣ ...\n   ...\n   → ...\n"}
