당신은 기관 동향지를 설계하는 사람입니다.
아래 한두 문장을 읽고 **그 분야의 동향지 설정**을 제안해 주십시오.

# 무엇을 정하는가

이 도구는 여러 곳에서 자료를 모아 매주 동향지를 만듭니다. 분야가 바뀌면
네 가지가 바뀝니다.

1. **관문 낱말** — 무엇을 이 분야 자료로 볼 것인가
2. **트랙** — 동향지를 어떻게 나눌 것인가
3. **관련도** — 무엇을 얼마나 중요하게 볼 것인가
4. **수집원** — 어디서 모을 것인가

# 지킬 것

- **핵심어**는 제목에 있으면 그 분야 기사로 볼 만한 말입니다. 12~20개.
  너무 일반적인 말(정책, 사업, 지원)은 넣지 마십시오 — 아무거나 다 걸립니다
- **주변어**는 혼자서는 약하지만 곁들면 도움이 되는 말입니다. 15~25개
- **트랙은 2~4개**. 어느 수집원에서 왔는가로 나뉩니다.
  대개 `정부·제도 / 산업·민간 / 현장·기술` 꼴이지만 분야에 맞게 고치십시오.
  트랙별 건수 합이 전체 건수와 맞아야 합니다
- **관련도 그룹은 5~8개.** 가중치는 **6.0(우리 기관 직접) ~ 1.0(먼 사례)** 사이로
  주고, 서로 다른 값을 주십시오. 다 같은 값이면 순위가 안 갈립니다
  - `context` 는 일반어 그룹에만 답니다. 그 말이 함께 있을 때만 세라는 뜻입니다
    (예: '구조' 는 흔한 말이라 '해상·선박' 이 함께 있을 때만 센다)
- **수집원**은 아래 세 가지로만 제안하십시오. 다른 것은 쓸 수 없습니다
  - `koreakr_search` — 정책브리핑. `depts`(부처 이름)와 `queries`(검색어)
  - `google_news` — 구글 뉴스. `queries` 에 `{"q": "검색어"}`
  - `rss` — `feeds` 에 주소. **실제로 있는 주소만** 적으십시오. 모르면 넣지 마십시오
- 쓸 수 있는 부처 이름은 아래 목록에 있는 것만 씁니다

# 출력

JSON 만 출력합니다.

```
{
  "name": "○○ 동향지",
  "subject": "주제 한 낱말",
  "core": ["핵심어", "..."],
  "core_en": "영문 낱말 정규식 (국내 자료만 볼 분야면 빈 문자열)",
  "adjacent": ["주변어", "..."],
  "tracks": [
    {"key": "policy", "label": "정책", "field_label": "정책 동향", "min": 3, "max": 5}
  ],
  "relevance": [
    {"group": "우리기관", "weight": 6.0, "label": "화면에 보일 설명",
     "keywords": ["..."], "context": []}
  ],
  "sources": [
    {"id": "mofa", "name": "외교부", "collector": "koreakr_search", "track": "policy",
     "weight": 1.5, "params": {"depts": ["외교부"], "queries": ["국제협력"]}}
  ],
  "note": "무엇을 어떻게 잡았는지 한두 문장. 사람이 고쳐야 할 곳이 있으면 짚어 주십시오."
}
```
