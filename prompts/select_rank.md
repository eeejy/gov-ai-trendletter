# 이번 호 항목 선별

아래는 최근 {{DAYS}}일간 수집·통합된 이슈 후보다. 이 중에서 「AI 정보동향지」
{{TOTAL_MAX}}건을 고른다.

## 선별 기준 (우선순위 순)

1. **국가AI전략위원회의 핵심 계획·의결·정책 권고는 무조건 포함한다.**
   범정부 AI 정책의 최상위 방향을 제시하기 때문이다.
2. 해양경찰 업무(수색구조·관제·방제·수사·경비·행정)에 직접 적용 가능한 것
3. 지휘부의 정책 판단에 필요한 상위 정책·예산·제도 변화
4. 여러 매체가 동시에 보도한 이슈 (기사 수가 아니라 **매체 수**로 판단)
5. 개발자 신호는 단순 언급량이 아니라 플랫폼 수 · 반응 증가 · GitHub/OpenRouter
   실제 활동이 함께 확인될 때만 채택한다.

## 구성 요건

- AI 정책 {{POLICY_MIN}}~{{POLICY_MAX}}건
- AI 산업·도구 {{INDUSTRY_MIN}}~{{INDUSTRY_MAX}}건
- 전체 {{TOTAL_MAX}}건 이내
- 같은 기관·같은 주제가 3건 이상 몰리지 않게 한다.

## 입력

```json
{{CANDIDATES_JSON}}
```

```json
  ],
  "dropped_notable": [
    {"cluster_index": 7, "reason": "제외 사유 한 줄"}
  ]
}
```
